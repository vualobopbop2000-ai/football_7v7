# NEON FOOTBALL — safe UI restore + practice mode

This package restores the original match interface, original canvas sizing, original camera/rendering and existing mobile control layout from the supplied files. It adds only the opening orientation notice, the solo-practice menu button, and an exit-practice overlay.

Replace these three files in your repository: `public/client.js`, `public/index.html`, and `public/style.css`. No server.js or package.json change is required for local practice.
